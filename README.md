# Fareeduddin Mohammed

I am a Research Associate at the Qatar Environment and Energy Research Institute (QEERI), part of Hamad Bin Khalifa University in Doha. I build web apps and machine learning models for energy data.

## Selected work

- [SolarIQ](https://github.com/farreedd/SolarIQ) is a React web app that shows the modeled solar potential of the Qatar Foundation campus. All values are synthetic, and the site runs in the browser only.
- [qgreen_website](https://github.com/farreedd/qgreen_website) is the public website of Q-Green, an energy analytics app that I built at QEERI and presented at Web Summit Qatar 2026.
- My first-author paper in [Energy and AI (2025)](https://doi.org/10.1016/j.egyai.2025.100625) describes a hybrid model of regression and neural networks that forecasts short-term electricity demand with 0.68% average error.

## Earlier work

At the Qatar Computing Research Institute (2021 to 2024), I built a machine learning pipeline that detects phishing websites with graph neural networks.

The code of Q-Green and of my QCRI work is not public.
